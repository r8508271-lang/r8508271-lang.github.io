Using a hook as a shovel

In this 50-object scene, the agent repurposes an L-shaped hook to scoop, carry, and pour objects across a divider. It repeats the maneuver to move additional loads. The strategy exploits the simulator's collision rules: the grasped hook can pass through static surfaces while still interacting with the objects. Watch how the agent changes the hook's orientation to collect and release each load.
